## What it is

An index: a short introduction, then curated links out to the vulnerability
management, threat hunting, and security operations projects.

## Rules

- **Edits are public and immediate.** This renders on the profile page as soon as
  it is pushed. Treat every change as publishing.
- **Check links before adding them.** A dead link on the profile page is the most
  visible possible broken thing. Confirm the target repo and path exist.
- Keep it an index. Project detail belongs in the project's own README, not here.
- Preserve the first-person voice — it reads as a person, not a spec sheet.
